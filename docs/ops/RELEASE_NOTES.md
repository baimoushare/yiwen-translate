# 版本更新日志

本文件是 GitHub Release 正文的唯一来源。每个可发布版本必须有一个同名的二级标题；发布工作流会读取对应章节并写入 Release。

## 0.0.7

### 修复与改进

- 修复稳定版检查更新可能受到 GitHub 匿名 API 限流影响的问题。
- 稳定版改用 GitHub Latest Release 静态更新源，减少办公室、校园网、VPN 和共享网络环境下的检查失败。
- 保留 beta 和私有 staging 更新通道的原有行为。

## 0.0.6

### 修复与改进

- 修复翻译服务下拉列表只能看到分类标题、无法直接选择具体服务的问题。
- 默认只显示无需配置即可使用的免费服务。
- 需要 API 或其他凭据的服务，只有完成配置后才会显示。
- 未配置的远程自定义服务不再显示；本地 OpenAI-compatible 服务可在无 API Key 时使用。
- 当前服务被删除或配置失效时，自动清理无效选择并回退到可用服务。
- 统一截图翻译、文字翻译、划词翻译和实时翻译中的服务选择行为。

## 0.0.5

### 修复与改进

- 修复混合 DPI、多显示器和负坐标环境下，截图选区可能被裁剪到错误位置的问题。
- 关于页新增 GitHub 项目入口和“检查更新”按钮。
- 增加截图识别失败时的可选诊断信息和帧转储，便于排查选区坐标问题。
- 修正实时翻译诊断帧的存储目录，使其与 Yiwen 应用目录一致。

## 0.0.4

### 新增与改进

- 新增百度、腾讯、有道、Google Cloud、Azure Translator 和 ChatGPT 翻译服务配置。
- 扩展智谱、Kimi、硅基流动、千问等 OpenAI-compatible 服务模板，并支持普通方案和 Coding Plan。
- 翻译服务选择器按传统翻译和 AI 翻译分组展示。
- 改进自定义翻译服务的添加、编辑、配置状态和服务选择体验。
- 修复截图开始时可能出现的黑色闪烁，并改进选区边缘取整，减少文字被裁掉的情况。

## 0.0.3

### 修复与改进

- 统一 Yiwen / 译文的应用品牌、安装包名称和下载说明。
- 将正式版自动更新源切换到 GitHub Releases。
- 明确 Yiwen 与上游 OverTranslate 使用独立的应用包名和更新通道。
- 更新项目 README 和发布说明，统一面向用户的产品信息。

## 0.0.2

### 新增与改进

- 新增简体中文界面，并将默认目标语言调整为简体中文。
- 支持多个自定义 OpenAI-compatible 翻译服务，可使用内置厂商模板快速配置。
- OpenAI-compatible 服务支持连接测试、获取模型列表、超时设置、提示词和 Temperature 配置。
- 新增界面字体选择、字体搜索和译文字号校准选项。
- 默认使用 Windows 本地语音合成，支持语音、速度和音量设置；截图翻译和划词翻译支持自动朗读。
- 改进剪贴板复制在被其他程序占用时的重试处理。
- 调整默认快捷键：截图为 `Ctrl+Alt+D`，划词为 `Ctrl+Alt+A`；打开主窗口的全局快捷键默认关闭。
- 重组设置页面，并更新应用图标和相关界面样式。
